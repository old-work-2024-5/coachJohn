# Coach John Website

This is the official website for Coach John Leadership & Community Engagement Initiative.

## Features

- Responsive design for all devices
- Photo gallery with support for 50+ images
- Video gallery with YouTube integration
- Programs information and registration
- Contact information and location
- Events calendar and registration
- Flyer templates for creating event materials

## Installation and Setup

### Prerequisites

- Node.js 18.0.0 or later
- npm or yarn
