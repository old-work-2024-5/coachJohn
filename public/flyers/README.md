# Event Flyers

This directory contains all event flyers that will be displayed on the website.

## How to add a new flyer:

1. Save your flyer image in this directory
2. Use a descriptive filename that includes the event name and date (e.g., `summer-basketball-camp-2024.jpg`)
3. Supported formats: JPG, PNG, PDF (for downloadable flyers)
4. Recommended image dimensions: 1200px × 1800px (portrait orientation)

The system will automatically detect new flyers based on the events configuration in the events.ts file.
