# Flyer Templates

This directory contains editable templates for event flyers. You can use these as starting points for creating new event flyers.

## How to use these templates:

1. Choose a template that matches your event type
2. Open the HTML file in a web browser to preview
3. Edit the HTML and CSS to customize the flyer
4. Save as PDF or export as an image
5. Place the final flyer in the `/public/flyers/` directory

Each template is designed to be easily customizable with your event details.
